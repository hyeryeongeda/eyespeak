## 추천 로직 개선

### 1. 유사 문장에서 형태소를 추출한다.

3. 최종 풀에서 상위 k개(기본 6개) 반환한다.

설치되어 있으면: 방향 2(유사문장→추출) 사용.
없으면: 기존 pastWords + 유사도·빈도 로직만 사용.
stt_recommendation/requirements.txt에 konlpy>=0.6.0 넣어 두었습니다.
방향 2 쓰려면: pip install konlpy (또는 해당 requirements 설치).
4. 동작 확인
서버 기동 시 로그로
[초기화] 형태소 분석(Okt) 로드됨 → 단어 추천 방향2(유사문장→추출) 사용
또는
[초기화] konlpy 미사용 → 단어 추천은 pastWords+유사도·빈도 로직 사용 (pip install konlpy 권장)
중 하나가 찍히도록 해 두었습니다.
이제 “오늘 무릎 많이 아팠어?” 같은 질문이 오면, 그 질문과 유사한 문장(예: “무릎 아파”, “어깨 아파”)에서 무릎, 어깨, 아파 같은 단어가 먼저 추출되고**, 그다음에 pastWords로 부족분이 채워집니다.
konlpy 설치 후 서버만 다시 띄우면 방향 2가 적용됩니다.

## 반성
- 같은 AI 담당 팀원에게 벡터 DB 도입 여부를 명확하게 전달하지 않아 폐를 끼쳤다. 내가 짠 추천 로직의 코드를 제대로 파악하지 않아 생긴 일이었다. 내가 코드를 제대로 파악하지 않아 담당 팀원에게 큰 혼선을 주었고, 결과적으로 팀원의 시간을 낭비하게끔 했다. 이 부분이 계속해서 마음에 걸리고 많이 미안하다. 다시는 같은 실수를 반복하지 않고, 팀원에게 폐를 끼치지 않도록 왜 이런 일이 발생했는지 원인을 생각해볼 필요가 있다.

### 첫번째, ADR 기록이 미흡했다.
- 추천 로직을 여러 번 변경하고, 버전도 바꾸고, 더미데이터도 이리저리 수정하면서 ADR을 제대로 적지 않았다. Bi-encoder와 Cross-encoder 사용에서 bi-encoder만 단독 사용으로, LLM 후처리를 문장 처리에만 사용하였다가 단어 처리에도 사용하는 등등 버전을 하루에도 두 세번씩 고쳐가며 로직을 변경했는데, ADR이라든지 기술 스택을 제대로 정리하지 않았다. 그래서 나조차도 현재 로직이 어떤 원리로 돌아가는지 헷갈리게 되니, 팀원에게 정확한 정보전달을 할 수 없었다.

### 두번째, 팀원 간 정보 공유가 미흡했다.
- 피드백을 받고 로직을 수정하는 데 급급해서 팀원에게 지금 추천 로직이 어떻게 돌아가는지 공유하지 않았다. 바쁜 일정이라도 적어도 어떤 기술을 쓰고 바꿨는지 노션에라도 기록을 남겨 놓았어야 했다.

### 개선 방법 1: 파일 정리를 습관화하기
이전에 STT_RECOMMENDATION 폴더에 이전 버전 4가지가 한꺼번에 들어있었다. 파일을 수정하고, 만들면서 이전 버전 관리를 하지 않았다. 따라서 깃허브에 파일 기록을 올리고, 현재 버전인 caregiver_server.py를 제외하고 모든 파일을 삭제하였다. 이뿐만 아니라 사용하지 않는 더미데이터도 삭제했다. 그렇게 하니 내가 지금 어떤 버전을 사용하고, 어떤 로직을 쓰고 있는지 파악이 이전보다는 용이해졌다.

### 개선 방법 2: 추천 로직 설명서 문서화하기
추천 팀멤버에게 어떤 로직으로 돌아가는지 알려주기 위해 ai 노션 페이지에 현재 로직의 설명서를 적었다. 설명서는 어떤 기술과 ai 모델을 사용하고 있는지, 각 기술의 분류는 어떻게 들어가는지부터 임베딩, 벡터, 코사인 유사도 등등 내 로직에 등장하는 개념들에 대해 개념정리부터 팀원이 할 수 있는 예상질문까지 정리해놓았다. 오늘(14일) 회의에서 팀원과 함께 문서를 공유하며 내용을 공유할 예정이다.

### 개선 방법 3: ADR 습관화하기
로직을 하나하나 적용할 때마다 ADR을 습관화해야겠다. 다만, 매번 수기로 작성이 힘드니 자동화할 수 있는 방법이 있는지 생각해볼 필요가 있다.


### 개선 방법 4: 내가 하는 행동이 팀 전체에 영향을 끼칠 수 있음을 잊지 않기
- 나의 장점은 추진력이 좋다는 것이고, 단점은 섬세함이 떨어진다는 점이다. 추진력으로 일을 밀고 나가다보면 섬세하지 못해서 문서화 누락이라든지, 개념을 잘못 알고 있다든지 하는 실수가 종종 발생한다. 혼자 한다면 나만 조금 고생하면 되지만, 팀 프로젝트를 할 때에는 이번처럼 팀원에게까지 피해가 간다. 내가 잘못한 일임에도 불구하고 팀원이 자기는 괜찮다고 다독여주어서 더욱 미안하다. 앞으로는 이런 일이 발생하지 않도록 더욱 주의를 기울여야겠다. 아직 배울 게 많고 갈 길이 멀다. 언제쯤이면 이런 실수를 반복하지 않는 사람이 되는 걸까.........................................
