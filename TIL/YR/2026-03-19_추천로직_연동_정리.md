# 추천 로직 연동 정리 (2026-03-19)

## 전체 구조

```
프론트엔드 (React, :3000)
    │
    │  API 호출: /api/recommendation/recommend 등
    ▼
Spring Boot (Java, :8080)
    │  RecommendationController
    │  → RestTemplate으로 Python 서버에 요청 전달
    │  → Python 응답을 ApiResponse로 감싸서 반환
    ▼
Python AI 서버 (Flask, :5003)
    │  caregiver_server_db.py
    │  → MySQL에서 데이터 조회
    │  → 임베딩 모델로 유사도 계산
    │  → LLM(gpt-4o-mini)으로 문장 정제
    │  → 추천 결과 반환
    ▼
MySQL DB (Docker, :3306)
    │  eyespeak 데이터베이스
    │  → expressions, general_corpus, user_words 등
```

## 로컬 실행 순서

### 1. Docker DB 띄우기
```bash
make local-up
```
- MySQL(:3306), Redis(:6379), RabbitMQ(:5672) 실행됨

### 2. Python AI 서버 띄우기
```bash
cd AI_TEST/YR/embedding/stt_recommendation
python caregiver_server_db.py
```
- 포트 5003에서 실행
- 임베딩 모델 로딩 + general_corpus 2900개 사전 계산 (1~2분 소요)
- `.env`에 `GMS_KEY`, `DB_HOST`, `DB_PASSWORD` 등 필요

### 3. Spring Boot 실행
- IntelliJ에서 `EyespeakApplication` 실행
- 포트 8080
- `application-local.yml`에서 `ai.server.url=http://localhost:5003` 읽음

### 4. 테스트
- Swagger: `http://localhost:8080/swagger-ui/index.html`
- Recommendation 섹션에서 Try it out → Execute

## JSON → DB 변경점 (caregiver_server.py → caregiver_server_db.py)

| 항목 | 기존 (JSON) | 변경 (DB) |
|------|-------------|-----------|
| 사용자 식별 | `user_id` (문자열) | `matching_id` (숫자) |
| 유저 데이터 로드 | JSON 파일 읽기 | `SELECT FROM expressions, usage_log, ...` |
| 범용 문장 로드 | JSON 파일 읽기 | `SELECT FROM general_corpus` |
| 표현 사용 기록 | JSON 파일에 쓰기 | `INSERT INTO expressions, usage_log` |
| 캐시 | 유저별 메모리 캐시 | 매 요청마다 DB 조회 (실시간 반영) |
| 의존성 추가 | - | `pymysql` |

## 추천 로직 파이프라인 요약

```
입력: question(질문), sentiment(감정), selected_category(카테고리)

① DB에서 데이터 로드
   - expressions + expression_keywords + usage_log → user_db
   - 각 표현의 weight = 1 + log(usageCount + 1)

② 감정 필터 (sentiment가 있으면)
   - user_db, general_corpus에서 해당 감정만 필터

③ 임베딩 유사도 검색 (Bi-encoder)
   - 모델: paraphrase-multilingual-MiniLM-L12-v2
   - 질문 벡터 ↔ 각 문장 벡터 → 코사인 유사도

④ 점수 계산
   - 최종점수 = 유사도 × weight × 시간대보정 × 의도보정

⑤ 혼합 검색
   - user_db 상위 3개 + general_corpus 상위 3개 = 후보 6개

⑥ LLM 정제 (gpt-4o-mini)
   - 후보 6개 → 자연스러운 문장 3개로 정제
   - 반말 구어체, 15자 이내

출력: 추천 문장 3개
```

## 주의사항

- Python 서버가 꺼져있으면 Spring Boot API 호출 시 500 에러 발생
- `ddl-auto: create`이므로 Spring Boot 재시작 시 테이블이 재생성되고 data.sql이 다시 실행됨
- 회원가입/로그인 완성 전까지는 `matching_id=1` (테스트 데이터)로 테스트
- Python 서버 첫 실행 시 임베딩 모델 다운로드 + 사전 계산에 1~2분 소요
