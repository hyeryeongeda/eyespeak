## 1. 구두점(punctuation) 단순화
- **변경**: 추천 구두점을 **6개 → 3개**로 축소 (`.`, `!`, `?`만 사용)
- **수정 파일**: `caregiver_server.py` (기본값·폴백), `als_patient_dataset.json` (`pastWords.punctuation`)
- **이유**: 6분할 UI에 맞춰 자주 쓰는 문장 부호만 노출

## 2. 의도(Intent) 기반 문장 추천
- **목적**: 감정만이 아니라 **의도(통증/욕구/감정/음식 등)**까지 반영해 문장 검색 정확도 향상
- **구현**:
  1. **LLM**: `_generate_categories`에서 `intentMap` 추가 생성  
     (예: `{"아파": "통증", "안 아파": "통증"}`)
  2. **검색**: `_search_sentences`에 `intent_filter` 추가  
     - 선택한 카테고리의 intent와 `pastExpressions.categories`가 일치하면 점수 **1.5배** 가산
  3. **API**:  
     - `POST /recommend`에 `selected_category` 추가 → 서버에서 intent 조회 후 intent 필터 적용  
     - `POST /categories` 응답에 `intentMap` 포함
  4. **프론트**: 카테고리 선택 후 `/recommend` 호출 시 `selected_category` 전달
- **효과**: "어깨 아파" → "아파" 선택 시, 통증 관련 과거 표현이 더 상위로 노출

## 3. 단어 추천 맥락 연결 (이전 선택 단어 반영)
- **문제**: 주어·목적어·서술어를 단계별로 **독립** 추천해서, 주어로 "손녀딸"을 골라도 목적어에 "물"이 먼저 나오는 등 맥락이 약함
- **해결**: **이전 단계에서 선택한 단어와의 유사도**를 점수에 반영
  - `context_boost = 1.0 + α × max(선택 단어 벡터와의 코사인 유사도)`  
    (α = 0.4, `_WORD_CONTEXT_ALPHA`)
  - `_search_words`에 `selected_words` 인자 추가  
    (형식: `{ "subjects": "손녀딸", "objects": "", "verbs": "" }`)
  - 나머지 후보 정렬 시 `score × context_boost` 적용
- **API**: `POST /words`, `POST /words_all`에 `selected_words` 옵션 추가
- **프론트**: `getSelectedWordsPayload()`로 이미 선택한 주어/목적어/서술어를 객체로 만들어, `renderWordStep`·`wordRefresh`에서 두 API 호출 시 함께 전달
- **효과**: 주어 "손녀딸" 선택 시 목적어에 "용돈", "간식" 등 연관 단어가 더 위로 올라옴
