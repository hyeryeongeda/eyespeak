# 2026-03-19 TIL

## 1. Swagger 추천 API 명세 완성
- `RecommendationController`에 5개의 POST API를 추가하였다. `/recommend`, `/categories`, `/words`, `/generate`, `/expressions/use` 총 5개의 엔드포인트를 명세하였으며, inner class에 `public` 접근제어자가 누락된 문제를 발견하고 수정하였다. Swagger를 통해 프론트엔드 팀과 API 인터페이스를 맞추기 위한 기반을 마련하였다.

## 2. JSON 데이터 → MySQL DB 이관
- 기존에 JSON 파일로 관리하던 추천 데이터를 MySQL DB로 이관하였다. `als_patient_dataset.json`과 `general_sentences_with_sentiment.json`을 분석하여, `generate_seed.py` 스크립트로 `data.sql`을 자동 생성하였다. Docker MySQL에 시드 데이터를 투입하고 검증하였으며, `general_corpus` 2,900개, `expressions` 79개, `keywords` 154개 등이 정상적으로 적재된 것을 확인하였다.

## 3. Python 추천 서버 DB 버전 생성
- 기존 JSON 파일 기반의 추천 서버를 보존하면서, DB 연동 버전인 `caregiver_server_db.py`를 별도로 신규 작성하였다. JSON 파일 읽기 방식을 MySQL 조회 방식으로 전환하였고, 식별자를 `user_id`에서 `matching_id`로 변경하였다. `.env`에 DB 접속 정보를 추가하고 `pymysql`을 설치하여 DB 연동 준비를 마쳤으며, DB 연동 전 API 동작 성공을 확인하였다.

## 4. Spring Boot ↔ Python 서버 연결
- `RestTemplateConfig.java`를 생성하여 `RestTemplate` Bean을 등록하였다. 기존에 하드코딩되어 있던 `RecommendationController`를 수정하여, Python 서버(포트 5003)를 RestTemplate으로 호출하는 방식으로 전환하였다. `application-local.yml`에 `ai.server.url` 설정과 `data.sql` 자동 실행 설정을 추가하여 로컬 개발 환경에서의 연동이 원활하게 이루어지도록 하였다.

## 5. ERD 정합성 수정
- `User.java`의 테이블명이 `users`로 설정되어 있던 것을 ERD 기준에 맞게 백틱을 사용하여 `` `user` ``로 수정하였다. MySQL 예약어 충돌 문제도 함께 해소하였다. 이를 계기로 22개의 전체 엔티티를 ERD와 전수 비교하였으며, 나머지 엔티티는 ERD와 일치함을 확인하였다.

## 6. SecurityConfig 수정
- `/api/recommendation/**` 경로를 인증 없이 접근 가능하도록 `SecurityConfig`에 추가하였다. Python 서버 연동 테스트 과정에서 인증 필터에 막히는 문제를 발견하고 수정한 것이다.

## 7. 문서화
- 오늘 작업한 추천 로직 연동 내용을 `TIL/YR/2026-03-19_추천로직_연동_정리.md`에 정리하였다. 인프라 팀에 요청할 사항(Docker 네트워크 설정, Python 컨테이너 추가, 배포 방법 등)과 내가 준비해야 할 사항(FastAPI 서버, Dockerfile, requirements.txt 등)을 정리하여, 이후 협업 시 참고할 수 있도록 하였다.
