##  📌 기획 디벨롭 - [채영]루게릭 환자를 위한 웹캠 eye-tracking 기반 AI 소통 플랫폼

### 1. 아이디어 개요

- **서비스 한 줄 요약**: 웹캠 기반 AI 아이트래킹 및 상황 예측 UI를 통해 루게릭병 환자의 의사소통 어려움을 해결하고 존엄성을 회복시키는 서비스
- **주요 타겟 사용자층**: **루게릭병(ALS) 환자 - 간병인(배우자 or 활동보조인)**
- **핵심 제공 가치**:
    - 환자가 관계의 주체가 되는 **'능동적 의존(Active Dependence)'** 지원
        - **능동적 의존**
            - 타인이 자신의 삶에 참여하도록 주도
            - 관계 속에서 존엄을 유지하려는 시도
            - 삶의 의미를 재구성
            
            ⇒ **우리가 개발할 기술은 단순 편의 도구가 아니라, 존엄을 회복시키는 매개체여야 함**
            
            **환자가 의사표현을 제대로 한 소통을 할 수 있다면 환자는 능동적 의존의 삶 형태로 나아갈 수 있다**
            
- **기획 배경**
    - 환자들이 루게릭병을 판정받으면 3~5년 내 사망할 수 있다는 말을 듣게 되는데, 이때 엄청난 충격과 절망감을 경험하고, 진단을 부인하거나 자신과 배우자를 원망하는 등 한동안 우울감과 자포자기의 마음에 사로잡혀 감당하기 힘든 심리적 어려움을 경험하게 됨. 또, 환자들은 병이 진행되면서 나타날 신체 변화에 대해서 큰 두려움과 좌절감을 느꼈음.
    - 루게릭병 투병 생활에서 :
        - 환자는 간병인(보통 배우자(or 가족 구성원) 간병인인 경우가 대부분)과 밀착된 일상을 보내게 되는데 여기서 **의견 차이와 서툰 의사소통으로 오해와 실망감을 경험** → 시행착오와 갈등 겪음.
        - 루게릭병 환자는 타인 돌봄 없이는 일상생활 불가능해졌으니 **배우자나 가족의 서툰 돌봄 방식으로 신체적 고통과 심리적 불안 겪었고, 도움 요청 시 미안함과 스트레스 느낌**
        - 또, 환자는 스스로 마음을 다스리면서 투병에서의 어려움을 극복하기 위해 긍정적이고 현실적인 사고 유지하려고 노력. **여기서 배우자(간병인)과의 원활한 의사소통과 깊은 유대가 가장 중요한 심리적 자원이 되었고, 여러 시행착오 통해 소통이 성숙해지면서 갈등 해소 및 신뢰 구축됨**
        - 즉, 배우자(간병인)의 주도적이고 노련한 돌봄 기술이 환자에게 신체적, 심리적 안정감을 제공함. 환자들은 가족에게 자신의 취약한 신체 상태를 적극적으로 이해시키고, 혼자 있는 시간을 줄이며, 가족들의 간병 부담을 덜어주기 위해 노력
        - **본인이 직접 의사소통을 더 할 수 있으면 환자와 배우자 모두에게 도움이 될 것이다!**
- **포인트**:
    - 탐색 스트레스 줄여주기 + 빠른 의사소통
- **User Flow 요약**:
    - 캘리브레이션을 통해 환경 세팅 → 웹캠 기반 아이트래킹 기술 서비스 활용 시작 → 상황별 맞춤 문장 추천/노출 → 환자 선택 → 간병인에게 의사 전달 및 피드백


### **2. 도메인 채택 당위성 (Why AI Video?)**

## Capacitor?

* Capacitor는 Ionic 팀에서 만든 오픈 소스 네이티브 런타임. 
* 웹 앱(React, Vue, Angular 등)을 네이티브 앱 컨테이너 안에서 실행할 수 있게 해주는 '브릿지' 역할
* **웹 앱의 패키징**: 작성한 React 코드를 네이티브 앱(IPA, APK)으로 변환해줌
* **네이티브 API 접근**: 웹 브라우저에서는 접근할 수 없는 카메라, GPS, 푸시 알림, 생체 인식(FaceID) 등의 기기 기능을 JavaScript로 제어할 수 있게 함.
* **표준 웹 기술 중심**: 하이브리드 앱의 조상 격인 Cordova의 현대적인 후계자로, 최신 웹 표준을 지향하며 성능이 더 빠르고 안정적임.

* React로 만든 웹 서비스를 모바일 앱으로 확장하고 싶을 때 Capacitor 사용
  * 주요 장점: 
    * 학습 곡선이 낮음 (React Native와 달리, 기존에 사용하던 react-dom과 웹 라이브러리(Tailwind CSS, MUI, Framer Motion 등)를 그대로 사용 가능)
    * 빠른 개발 속도 (하나의 코드 수정 시 웹과 앱 동시 반영됨)
    * 유연성 (이미 운영 중인 React 웹 사이트가 있다면, Capacitor 추가하는 것만으로도 며칠 내 앱 스토어 출시 준비 마칠 수 있음)

* 작동 원리
  * React 프로젝트 빌드해서 정적 파일(html, css, js) 생성함
  * -> Capacitor가 이 빌드된 파일들을 Android/iOS 네이티브 프로젝트 폴더로 복사
  * -> 모바일 기기에서 앱 실행 시, Capacitor가 내부적으로 WebView(일종의 내장 브라우저) 띄워서 빌드된 웹 콘텐츠를 보여줌
  * -> 사용자가 카메라 버튼 누르면 JavaScript 코드가 Capacitor 브릿지를 통해 기기의 실제 카메라 기능 호출하게 됨

#### React 프로젝트에 Capacitor 적용하는 과정
1. 설치 : `npm install @capacitor/core @capacitor/cli`
2. 초기화 : `npx cap init`
3. 플랫폼 추가 : `npx cap add android` or `npx cap add ios`
4. 동기화 : `npx cap sync` (리액트 빌드 결과물을 네이티브 플젝에 반영)
5. 실행 : `npx cap open android` (Android Studio 실행)
