- **시도**: MobileNetV3-Small + 64×64 눈 크롭 → 화면 좌표 직접 예측

**채택 전략**: CNN 포기 → **동공 검출(이미지 처리) + 9점 다항식 캘리브레이션** 방식으로 전환

## 3. 동공 검출 (`findPupilCenter()` in `eye_mouse.js`)

```
gray  = 0.299R + 0.587G + 0.114B
darkW = (1 - gray)^3                  // 어두울수록 가중치 급상승
spatW = exp(-(dx²+dy²) / 2σ²)        // 중앙 선호
centroid = (Σ x·w / Σw,  Σ y·w / Σw) → [0,1] 정규화
```

단순 최소값 픽셀 대신 "어두움 × 중앙 선호" 가중치로 노이즈에 강한 무게중심 계산.
(`PUPIL_SPATIAL_SIGMA=0.35`, `PUPIL_DARK_POWER=3`)

## 4. 9점 캘리브레이션 + 2차 다항식 회귀 (`eye_mouse.js`)

- 9점 응시 → 2.5초 샘플 수집 → 중앙값(median)으로 이상치 제거
- 특징 벡터 `f = [1, x, y, xy, x², y²]` 로 최소자승법 회귀 (가우스 소거법, 순수 JS 구현)
- 스무딩: `smoothX = 0.15 × predictedX + 0.85 × smoothX` (EWM, α=0.15)

### ⚠️ Problem — 문제였던 것

**CNN 모델에 너무 오래 매달렸다**

`train_gaze.py → train_gaze_v2.py → train_gaze_aihub.py` 로 여러 버전을 반복하면서 결국 739px 오차라는 결론에 도달했다. 처음부터 head pose 정규화 문제를 인지했다면 실험 횟수를 크게 줄일 수 있었음

**캘리브레이션 정확도를 실제로 측정하지 않았다**

웹 데모를 완성했지만 "9점 캘리브레이션 후 실제 픽셀 오차가 얼마인가"를 정량적으로 측정하지 않아서, 동작은 하지만 충분히 쓸 수 있는 수준인지 아직 모름

**실험 결과 기록이 분산되어 있다**

`exp4`, `exp6`, `exp7`, `exp8` 등 YOLO 실험이 여러 개 쌓였고, 각각의 하이퍼파라미터 변경 이유와 결과 비교가 한 곳에 정리되어 있지 않다. 나중에 "왜 exp6을 골랐는가"를 추적하기 어려움
