# TIL 회고 - 2026.03.04


## 오늘 학습 내용 정리

### 1. MPIIGaze 데이터셋 구조 이해
- **원본(Original)**: `p{id}/day{d}/` 폴더 구조, `annotation.txt` 41개 필드
  - [0-11]: 오른눈 6개 랜드마크 (x, y)
  - [12-23]: 왼눈 6개 랜드마크 (x, y)
  - [24-25]: 화면 시선 목표 좌표 (screen_x, screen_y)
  - [29-31]: 3D 시선 방향벡터 (yaw, pitch, roll)
- **정규화(Normalized)**: `.mat` 파일, 36×60 눈 크롭 + 3D 시선벡터 포함

### 2. YOLOv8 눈 탐지 파이프라인 구축
- `prepare_yolo_data.py`: annotation.txt → YOLO 라벨(.txt) 변환
  - 눈 랜드마크 6개 포인트 → bounding box (cx, cy, w, h) 정규화
  - 피험자 단위 분할: train(p00~p11), val(p12~p14)

- **실험 진행 결과**

| 실험 | 모델 | 데이터 | 결과 |
|------|------|--------|------|
| exp1~3 | YOLOv8n | 소규모 | 파이프라인 검증 |
| exp4 | YOLOv8n | 20k 서브셋 | mAP50 **0.830** (17 epoch) |
| exp5 | YOLOv8s | 209k 풀셋 | 학습 진행 중 |

- **exp4 문제 인식**: Precision ≈ 0.96 vs Recall ≈ 0.46 → 탐지 누락 많음

### 3. MobileNetV3-Small 시선 추정 모델
- 입력: 64×64 RGB 눈 크롭
- 출력: (yaw, pitch) — 라디안 단위 시선 방향
- Loss: SmoothL1 + Mean Angular Error (도 단위)
- 데이터: 418,102개(train) / 9,214개(val), `.npy` 캐시로 반복 로딩 제거
- 모델: MobileNetV3-Small (1.08M params), 경량화 중점

### 4. 전체 파이프라인 설계
웹캠/이미지
↓
YOLOv8 (눈 탐지 → Bounding Box)
↓
눈 영역 크롭 (64×64)
↓
MobileNetV3 (시선 방향 추정 → yaw, pitch)
↓
화면 좌표 변환 → AAC 입력


### 5. 실시간 학습 모니터링 노트북 (monitor_training.ipynb)
- 30초 주기 자동 갱신, Dark mode 대시보드
- 패널 구성: 진행률 바, Box/Cls/DFL Loss, mAP50, Precision/Recall, LR Schedule
