# 1️⃣ 아이트래킹 AI 모델 학습 (Gaze Estimation)

## 🎯 목표

사용자의 **눈 이미지와 머리 방향(Head Pose)** 정보를 이용해\
**카메라 기준 시선 좌표 (XCam, YCam)** 를 예측하는 모델을 구현했다.

입력 데이터

    left_eye image
    right_eye image
    head_pose [yaw, pitch, scale]

출력

    (XCam, YCam)

데이터셋: **GazeCapture Dataset**

------------------------------------------------------------------------

## ⚙️ 모델 아키텍처

### EyeEncoder

눈 이미지를 특징 벡터로 변환하는 CNN 인코더.

Backbone

    MobileNetV3-Small

구조

    Eye Image
       ↓
    MobileNetV3 features
       ↓
    Global Average Pooling
       ↓
    Linear Projection (576 → 128)

핵심 특징

-   **Transfer Learning 적용**
-   **Left/Right Eye Weight Sharing**
-   파라미터 수 감소 및 일반화 성능 개선

------------------------------------------------------------------------

### HeadPoseEncoder

GazeCapture에는 실제 **3D Head Pose**가 없기 때문에\
**Face Bounding Box 기반 프록시 Head Pose**를 사용했다.

입력

    [yaw, pitch, scale]

Encoder

``` python
HeadPoseEncoder
MLP(3 → pose_features)
```

머리 방향 정보를 임베딩하여 시선 예측 정확도를 보완한다.

------------------------------------------------------------------------

### GazeRegressor

눈 특징과 헤드포즈 특징을 **Feature Fusion** 후\
2D 시선 좌표를 회귀한다.

``` python
# gaze_model.py

fused = torch.cat([feat_l, feat_r, feat_p], dim=1)

return self.regressor(fused)  # (B,2) → XCam, YCam
```

최종 출력

    (XCam, YCam)

------------------------------------------------------------------------

## 📚 학습 파이프라인

학습 스크립트

    train_gaze.py

구성

-   Dataset: `GazeCaptureDataset`
-   Loss: `SmoothL1Loss`
-   Metric: `MAE`
-   Mixed Precision Training: `AMP`

학습 흐름

    Eye Images + Head Pose
            ↓
    EyeEncoder / PoseEncoder
            ↓
    Feature Fusion
            ↓
    GazeRegressor
            ↓
    (XCam, YCam)

------------------------------------------------------------------------

## 💡 핵심 구현 포인트

-   **MobileNetV3 기반 Eye Feature Extraction**
-   **Shared Eye Encoder**
-   **Bounding Box 기반 Head Pose Proxy**
-   **Camera Coordinate Direct Regression**

# 2️⃣ 환자 개인화 TTS 데이터셋 구축 (XTTS)

## 🎯 목표

환자의 음성을 기반으로 **개인화 TTS 모델(XTTS)** 을 학습하기 위해\
**자동 데이터셋 생성 파이프라인**을 구축했다.

입력

    YouTube 음성 / 기존 녹음 음성

출력

    LJSpeech Format Dataset

구조

    dataset/
     ├─ wavs/
     │   ├─ audio1.wav
     │   ├─ audio2.wav
     │   └─ ...
     └─ metadata.txt

------------------------------------------------------------------------

## ⚙️ 데이터셋 생성 파이프라인

전체 흐름

    Audio Source
       ↓
    Whisper Speech Recognition
       ↓
    Sentence Segmentation
       ↓
    FFmpeg Audio Split
       ↓
    LJSpeech Metadata 생성

------------------------------------------------------------------------

## 1️⃣ Whisper 음성 인식

음성에서 문장 단위 텍스트를 추출하기 위해\
**faster-whisper**를 사용하였다.

``` python
WhisperModel.transcribe()
```

Whisper는 **segment generator** 형태로 결과를 반환한다.

``` python
segments = list(segments)
```

각 segment에는 다음 정보가 포함된다.

    segment.start
    segment.end
    segment.text

------------------------------------------------------------------------

## 2️⃣ FFmpeg 오디오 분할

Whisper의 timestamp를 이용해 문장 단위 오디오를 생성한다.

``` python
def split_audio_segments(audio_path, segments_list, wavs_dir):

    for i, segment in enumerate(segments_list):

        start, end = segment.start, segment.end
        output_file = f"audio{i+1}.wav"

        command = [
            "ffmpeg",
            "-y",
            "-i", audio_path,
            "-ss", str(start),
            "-to", str(end),
            output_file
        ]

        subprocess.run(command)
```

결과

    audio1.wav
    audio2.wav
    audio3.wav
    ...

------------------------------------------------------------------------

## 3️⃣ LJSpeech 메타데이터 생성

XTTS 학습은 **LJSpeech Dataset Format**을 사용한다.

형식

    audio_file | transcription | normalized_text

예시

    audio1|안녕하세요 반갑습니다|안녕하세요 반갑습니다
    audio2|오늘 날씨가 좋네요|오늘 날씨가 좋네요

파일 위치

    dataset/metadata.txt
