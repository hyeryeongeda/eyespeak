# 2026-02-26 회고 

## KEEP (유지할 것)
- Git 작업을 감으로 하지 않고, `fetch → switch → pull → add → commit → push` 순서로 체크하면서 진행한 점
- “아이디어가 어렵다”를 그냥 넘기지 않고, 설명 가능한 구조(문제-해결-사용자흐름)로 쪼개려 한 점

## PROBLEM (문제)
- 아이디어가 머릿속엔 있는데 문장으로 설명할 때 범위가 계속 커지거나 흐려짐
- Git/Jira 컨벤션이 익숙하지 않아 중간에 멈칫하고 속도가 떨어짐
- 아이디어부분에 있어서 ai부분이 약하다보니 제한적으로 구상하게 된다.

## TRY (다음에 시도할 것)
- 아이디어를 5문장으로 고정해두고(한 줄 요약/타겟/핵심 기능/데이터/성과지표) 그 이상은 MVP 이후로 미룸
- 다양하게 아이디어 생각해보자
