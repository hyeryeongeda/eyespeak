## 후보 1) 원하는 장면만 바로 찾아주는 앱 (영상 구간 검색)

**한 줄 요약**

긴 영상에서 원하는 내용을 **말로 검색**하면, 해당 **장면(몇 분 몇 초)**으로 바로 점프하고 필요하면 **클립**까지 뽑아주는 서비스.

**문제 (Pain)**

- 영상은 길고, 내가 찾는 건 **몇 초**인데 대부분 **수동 스크럽**으로 찾음.
- 유튜브/강의/회의/리뷰에서 자주 생기는 요청:
  - “결론 말한 부분 어디야?”
  - “가격/장단점 언급한 구간만 보여줘”
  - “그 장면(웃긴 컷/특정 인물/특정 행동)만 찾아줘”
- 기존 검색의 한계:
  - 자막 없거나 부정확하면 검색이 막힘
  - 화면 기반 정보(인물/사물/상황)는 키워드만으로 놓치기 쉬움

**한 줄 해결 (Solution)**

- 영상을 **구간(씬/세그먼트) 단위로 미리 분석**해 요약/키워드/태그를 저장해두고, 사용자가 자연어로 검색하면 **관련 구간을 찾아 바로 재생/점프**한다.

**핵심 기능 (Core)**

- 영상 업로드/링크 등록 → 자동 분석(구간 분할 + 요약/키워드)
- 자연어 검색 → 결과 리스트(타임스탬프 + 한 줄 요약)
- 클릭 시 해당 구간으로 점프(플레이어 타임 이동)
- (선택) 구간 클립 추출(15~60초 등)

**MVP 범위 (최소 구현)**

- **텍스트 기반(자막/음성→텍스트)**만으로 1차 구현
  - 구간 분할: 일정 길이(예: 15~30초)로 청크
  - 각 청크: 요약 + 키워드 생성 → 저장
  - 검색: 쿼리와 청크 요약/키워드를 비교해 Top-N 반환
  - 플레이어: 타임스탬프 점프
- (확장) 화면 기반 태깅(객체/인물/행동) 추가

**기술 메모 (구현 방향 힌트)**

- 인덱싱: 청크 요약/키워드 임베딩 → 벡터 검색
- 랭킹: 벡터 유사도 + 키워드 매칭 혼합
- UX: “검색 → 결과(시간/요약) → 클릭 즉시 점프”가 핵심

**기대 효과**

- **시간 절약**: “어디쯤이더라”를 몇 초 안에 해결
- **검증 가능**: 답을 글로만 주지 않고 **바로 그 장면**으로 이동
- **재사용**: 한 번 분석한 영상은 아카이브처럼 계속 검색

## 후보 2) AI 쇼츠 자동 제작기 (롱폼 → 쇼츠 자동 편집)

**한 줄 요약**

긴 영상 링크를 넣으면 AI가 **볼만한 구간을 골라 15~60초 쇼츠로 자동 편집**하고, **자막/세로비율**까지 적용해 바로 업로드 가능한 파일을 만든다.

**문제**

- 쇼츠 제작은 “하이라이트 찾기 → 자르기 → 자막 → 세로 화면 맞추기”가 대부분 수작업.
- 영상은 있는데 쇼츠 업로드가 막히는 구간이 **편집 부담**임.

**한 줄 해결**

- AI가 하이라이트를 자동 선정하고 쇼츠 포맷(자막/세로)에 맞춰 출력한다.

**핵심 기능**

- 링크 입력 → 하이라이트 후보 N개 생성
- 자동 컷 편집(인트로/후킹 구간 강조)
- 자동 자막(싱크/강조)
- 9:16 리프레임(인물 중심 크롭) / 워터마크(선택)

**MVP 범위**

- 하이라이트 선정 1차: 음성/자막 기반(강조 발화, 특정 키워드, 질문-답변 구간)
- 자막: 자동 생성 + 기본 스타일 1종
- 출력: mp4 1개 또는 후보 3개

**기대 효과**

- 편집 시간 절감 → 업로드 빈도 증가 → 유입/조회 성과 기대

## 후보 3) 수어 실시간 번역/대화 보조 앱 (양방향 + 기록)

**한 줄 요약**

수어를 카메라로 비추면 **한국어 자막**으로 보여주고, 상대의 말(음성/텍스트)도 **실시간 자막**으로 제공해 대화를 이어주는 보조 도구.  
대화 내용을 저장/요약해 “기록/공유”까지 지원.

**문제**

- 통역이 상시 제공되지 않는 환경에서 대화가 끊기고 오해가 생김.
- 농인-농인 환경에서도 회의/교육/상담은 기록/공유 니즈가 큼.

**한 줄 해결**

- 대화 모드(양방향 자막) + 기록 모드(저장/요약/공유)를 제공한다.

**핵심 기능**

- 수어 → 한국어 텍스트 변환(실시간)
- 상대 음성 → 자막(실시간)
- 기록 저장 / 요약 / 키워드 / 내보내기

**MVP 범위**

- 제한된 도메인(예: 병원/민원/학교)로 표현 범위를 좁혀 정확도 확보
- “기록 모드” 중심으로 먼저 가치 증명 가능

## 후보 4) 딥페이크 1차 판별기 (영상 진위 스크리닝)

**한 줄 요약**

영상을 넣으면 AI가 **가짜일 가능성 점수**와 **의심 구간(타임라인)**을 표시해 빠른 검토를 돕는 1차 필터.

**문제**

- 딥페이크는 일반인이 눈으로 구분하기 어려워지고, 허위정보/사기 피해로 이어짐.
- 공유/게시 전에 “일단 걸러보는 1차 검사”가 필요.

**한 줄 해결**

- 확정 판정이 아니라 **스크리닝(위험도 + 의심 구간 제시)**에 집중한다.

**핵심 기능**

- 업로드 → 위험도 점수
- 타임라인에 의심 구간 마킹
- 근거(얼굴/입모양/프레임 불일치 등) 힌트 표시

**MVP 범위**

- 단일 모델 기반 점수 + 의심 프레임 상위 N개 표시 정도로 시작

## 후보 5) AI 눈 증상 네비게이터 (1차 선별 + 행동 가이드)

**한 줄 요약**

눈 증상/상황을 입력하면 “지금 해야 할 행동(즉시/오늘/며칠 관찰)”을 안내하고 위험 신호는 강하게 내원을 유도하는 1차 안내 서비스.  
(진단이 아니라 선별/안전 안내/기록 중심)

**문제**

- 충혈/통증/시야 흐림 같은 증상에서 응급 여부 판단이 어려움.
- 위험 신호(급격한 시야 변화 등)를 놓치면 문제.

**한 줄 해결**

- 1분 문진으로 위험도를 분기하고 “다음 행동”을 명확히 제시한다.

**핵심 기능**

- 증상 체크 + 상황 질문(렌즈/통증/시야 변화 등)
- 결과 카드(지금 할 일 / 주의 신호 / 관리법)
- 기록 저장(다음 진료 시 설명 도움)

**MVP 범위**

- 규칙 기반 트리아지(의학적 위험 신호 체크리스트) + 문구 템플릿
- (확장) 기록 데이터 기반 개인화

---

## 비교 기준(선정용 체크리스트)

- **AI가 꼭 필요하냐?** (규칙으로 대체 불가한 지점이 있는지)
- **MVP가 빠르게 되냐?** (2~3주 내 가치 시연 가능)
- **데이터/모델 리스크가 감당되냐?** (학습 데이터 없이도 가능한지)
- **데모 임팩트가 있냐?** (사용자가 한 번에 “오 된다” 느끼는지)
