# 2026-03-03 TIL

## 개요

루게릭병(ALS) 환자들의 단절된 소통을 돕기 위한 시선 추적 기반 AI 플랫폼 **'아이스픽(EYE SPEAK)'**의 MVP(Minimum Viable Product)를 설계함. 단순한 기술 구현을 넘어 환자의 생존과 직결된 안전장치와 실질적인 소통 속도를 개선할 수 있는 기술적 차별화 포인트를 구체화함.

## 1. 서비스 핵심 기능 및 MVP 설계

* **SOS 긴급 호출 시스템:** 거동이 불편한 환자가 위급 상황 시 시선만으로 보호자나 의료진에게 즉각적인 알림을 보낼 수 있는 생존 필수 기능.

* **2단계 3분할 시선 입력 UI:** 지난 학습에서 도출한 '피로도' 문제를 해결하기 위해 화면을 크게 3개 영역으로 나누고, '영역 선택 -> 세부 문장 확정'의 2단계 프로세스를 도입하여 오입력과 안구 피로를 최소화함.

* **RAG 기반 개인화 문장 추천:** 사용자의 과거 대화 맥락을 학습하여 상황에 적합한 문장을 우선 제안함으로써, 시선 입력의 물리적 한계인 '느린 소통 속도'를 소프트웨어적으로 보완.

* **본인 목소리 복원 TTS:** 질병 진행 전 기록된 환자의 목소리를 AI로 학습시켜, 기계음이 아닌 '나의 목소리'로 가족과 대화할 수 있는 정서적 가치 제공.

## 2. 기술적 검토 및 구현 전략

* **Webcam 기반 범용성 확보:** 전용 하드웨어 없이도 노트북(Lenovo 16AHP10 등)의 기본 웹캠만으로 작동하도록 **WebGazer** 및 **MediaPipe** 라이브러리 활용 방안 검토.

* **L2CS-Net 도입:** 일반 웹캠 환경에서도 시선의 미세한 각도(Yaw, Pitch)를 정밀하게 추적하기 위해 딥러닝 기반의 L2CS-Net 모델 분석 및 브라우저 환경 최적화 가능성 확인.

* **데이터 경량화:** 실시간 시선 추적 시 발생하는 연산 부하를 줄여 웹 환경에서도 끊김 없는 사용자 경험을 제공하기 위한 로직 구상.

## 3. 시장 조사 및 대외 협력

* **도메인 분석:** 국내 루게릭병 환자의 연령대별 분포를 조사하여 주 타겟층에 맞는 UI 크기 및 폰트 가독성 기준 설정.

* **외부 전문가 자문 요청:** 서비스의 실효성을 검증받기 위해 **승일희망재단**에 기능 자문 및 환자/보호자 심층 인터뷰 협조 요청 메일 발송. 현장의 목소리를 반영한 '진짜 필요한 서비스'를 만드는 것에 집중.

## 4. KPT (Keep / Problem / Try) 회고

### Keep (지속할 점)

* 기술적 화려함보다 '환자의 생존과 소통'이라는 본질에 집중하여 MVP 우선순위를 설정한 점.

* 논문(L2CS-Net)과 라이브러리를 병행 조사하며 기술적 근거를 탄탄히 쌓아가는 과정.

### Problem (개선할 점)

* 시선 입력의 물리적 속도 한계를 LLM(RAG)이 어느 정도까지 커버해 줄 수 있을지에 대한 구체적인 벤치마킹 데이터 부족.

* 웹 브라우저 환경에서 딥러닝 모델 구동 시 발생할 수 있는 리소스 점유율 문제.

### Try (시도할 점)

* **Prototype 제작:** MediaPipe Face Landmarker를 활용해 실제 브라우저에서 시선 좌표가 얼마나 안정적으로 튀지 않고 잡히는지 프로토타입 구현하기.

* **TTS API 연동:** 본인 목소리 복원을 위한 감성 TTS 엔진(ElevenLabs 등)의 한국어 성능 및 레이턴시 테스트 진행.
