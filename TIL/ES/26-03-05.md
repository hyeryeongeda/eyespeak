## 1. 데이터 구조 파악

AI Hub에서 받은 안구 움직임 데이터셋의 구조를 분석했다.

```
VS_G1/
└── 526/ (사람 번호)
    └── 30/ (촬영 거리 30cm)
        ├── IR/   → 적외선 눈 이미지 (.png)
        ├── RGB/  → 컬러 눈 이미지 (.png)
        └── XY/   → 시선 좌표 (.csv)
```

CSV 안에는 정규화된 화면 응시 좌표가 들어있다.

```
x: 0.5002  → 화면 가로 위치 (0.0 ~ 1.0)
y: 0.4988  → 화면 세로 위치 (0.0 ~ 1.0)
```

파일명 규칙으로 이미지와 CSV를 1:1 매칭했다.

```
이미지: NIA_EYE_G1_526_30_RGB_F_0001_mod.png
CSV:    NIA_EYE_G1_526_30_XY_F_0001.csv
                               ↑ F_0001 으로 매칭
```

총 **28,080쌍** 수집 완료.

## 2. CNN 학습

### 학습 구조

```
입력 (X): 눈 이미지 (64x64 grayscale)
출력 (Y): 화면 응시 좌표 (x, y)
```

### 모델 구조 (GazeCNN)

```
이미지 입력 (1x64x64)
    ↓
Conv2d → BN → ReLU → MaxPool  (32채널)
    ↓
Conv2d → BN → ReLU → MaxPool  (64채널)
    ↓
Conv2d → BN → ReLU → MaxPool  (128채널)
    ↓
Conv2d → BN → ReLU → MaxPool  (256채널)
    ↓
Flatten → Linear → ReLU → Dropout
    ↓
Linear → Sigmoid
    ↓
x, y 좌표 출력
```

### 학습 결과

| | IR 학습 | RGB 학습 |
|---|---|---|
| 초기 손실 | 0.0505 | 0.0512 |
| 최종 손실 | 0.0165 | 0.0123 |
| 오차 (1920x1080) | 약 32px | 약 24px |

RGB 데이터로 학습한 결과가 더 좋게 나왔다.

### GPU 설정

처음에 CPU로 학습되는 문제가 있었다. PyTorch CUDA 버전을 재설치해서 해결했다.

```bash
pip uninstall torch torchvision -y
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

## 3. 실시간 연결

학습된 모델을 웹캠에 연결했다.

### 핵심 흐름

```
웹캠 프레임
    ↓
MediaPipe로 눈 위치 찾기
    ↓
눈 영역만 크롭 (양쪽 눈 평균)
    ↓
64x64 리사이즈 → CNN 입력
    ↓
x, y 좌표 예측
    ↓
캘리브레이션으로 보정
    ↓
칼만 필터로 떨림 제거
    ↓
마우스 이동
```

### 눈 크롭이 필요한 이유

학습 데이터는 눈 클로즈업 이미지인데, 웹캠은 얼굴 전체가 찍히기 때문에 눈 영역만 잘라서 넣어야 한다.

```
학습 데이터 → 눈만 찍은 1024x1024 이미지
웹캠 입력   → 얼굴 + 배경 640x480 이미지
→ 눈 영역 크롭 없이는 AI가 엉뚱한 좌표 출력
```

### 캘리브레이션

사람마다 눈 크기, 눈 간격, 카메라 거리가 다르기 때문에 개인화 보정이 필요하다. 처음에 9포인트로 시작했다가 버튼 위치 4포인트로 줄였더니 해당 영역 정확도가 올라갔다.

## 4. 버튼 테스트 앱

4개 버튼을 시선으로 선택하는 테스트 앱을 만들었다.

### Dwell 방식

버튼 위에 **1.5초** 시선이 머물면 선택된다. 손을 쓰지 않고 눈만으로 선택하는 방식이다.

```
시선이 버튼 위에 올라감
    ↓
하단에 진행바 표시 (0 → 100%)
    ↓
1.5초 채워지면 선택!
```
