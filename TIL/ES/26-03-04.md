## MediaPipe만 사용했을 때의 한계

MediaPipe는 얼굴 **랜드마크**를 추적하는 도구라서, 눈이 얼굴 어디에 있는지는 알 수 있지만 눈동자가 어디를 **보고 있는지**는 알 수 없다.

- 얼굴이 왼쪽으로 돌면 → 눈 좌표도 왼쪽으로 이동 ✅
- 얼굴 가만히 있고 눈동자만 굴리면 → 좌표 거의 안 변함

### 진짜 시선 추적을 하려면?

```
눈동자 위치 (MediaPipe)
         +
홍채가 눈 안에서 어느 쪽으로 치우쳐 있는지 (비율 계산)
         =
시선 방향 추정
```

## 데이터셋 활용 인사이트 - End-to-End 모델로 합치기

### 기존 방식 (2단계)
안구 탐지와 시선 추정을 별도 모델로 분리해서 처리할 것으로 계획했음

```
이미지 → [안구 탐지 모델] → 안구 좌표
                                  ↓
              안구 좌표 → [회귀 모델] → 화면 좌표
```

### 개선된 방식 (End-to-End)
하지만 AI Hub 데이터셋에는 **안구 위치 + 시선 좌표**가 함께 들어있는 것을 발견하였다. 그래서 굳이 단계를 나누지 않고 하나의 모델로 합칠 수 있겠다는 생각을 하였다.

```
이미지 → [통합 모델] → 화면 좌표
```

### 학습 방법
- **X값 (입력)**: 이미지
- **Y값 (출력)**: 홍채 좌표 (또는 화면 응시 좌표)

### 장점
- 오차 누적 감소 (중간 단계가 없으므로)
- 구조가 단순해져 관리가 쉬움
- 데이터셋이 두 정보를 모두 포함하므로 End-to-End 학습 가능

## 1단계: Python으로 MediaPipe + 9 포인트 캘리브레이션

코드는 `./python/eye_tracking.py` 참조

### 시선 추적 코드에 쓰인 기술 정리

---

#### 1. MediaPipe Face Mesh

얼굴에서 **468개 랜드마크**를 실시간으로 추출한다. 눈썹, 코, 입, 눈꺼풀, 홍채 등 얼굴의 모든 부위가 좌표로 표현된다.

이 중 우리가 실제로 사용하는 건 **홍채 8개 점**뿐이다.

```python
L_IRIS = [474, 475, 476, 477]  # 왼쪽 홍채
R_IRIS = [469, 470, 471, 472]  # 오른쪽 홍채
```

---

#### 2. 정규화 (Normalization)

홍채 좌표를 그대로 사용하면 안 된다.  
카메라에 가까이 갈수록 눈이 크게 보이고, 멀어질수록 작게 보이기 때문에 같은 방향을 봐도 좌표값이 달라지기 때문이다.

이를 해결하기 위해 **눈 너비 대비 홍채 위치 비율**로 변환한다.

```
홍채가 눈 왼쪽 끝에서 얼마나 떨어졌는지
─────────────────────────────── = 0.0 ~ 1.0 사이 값
         눈 전체 너비
```

이렇게 하면 거리에 관계없이 같은 방향을 보면 같은 값이 나온다.  
다만 완벽하지 않아서 카메라에 가까이 있을수록 정확도가 높다. (추후 개선 가능)

---

#### 3. 캘리브레이션 + 선형 회귀

사람마다 눈 크기, 눈 간격, 카메라 거리가 다르기 때문에 캘리브레이션이 필요하다.

9개 포인트를 응시하는 동안 아래와 같은 데이터가 쌓인다.

```
왼쪽 위 응시  → 홍채 비율값 [0.3, 0.4, 0.3, 0.4]
오른쪽 위 응시 → 홍채 비율값 [0.7, 0.4, 0.7, 0.4]
가운데 응시   → 홍채 비율값 [0.5, 0.5, 0.5, 0.5]
```

**선형 회귀**는 이 데이터를 바탕으로 홍채 비율값 → 화면 좌표 간의 관계를 수식으로 학습한다.

```
화면X = a*홍채Lx + b*홍채Ly + c*홍채Rx + d*홍채Ry + e
화면Y = f*홍채Lx + g*홍채Ly + h*홍채Rx + i*홍채Ry + j
```

한 줄 요약:
> **9개 캘리브레이션 포인트를 기준으로, 홍채가 이 위치면 화면의 저 좌표를 보고 있을 확률이 높다고 추정해서 반환하는 것**

---

#### 4. 칼만 필터 (Kalman Filter)

눈은 항상 미세하게 떨리기 때문에 필터 없이는 마우스 커서가 덜덜 흔들린다.

칼만 필터는 **현재 측정값 + 이전까지의 움직임 패턴**을 합쳐서 가장 그럴듯한 실제 위치를 추정한다.

GPS 네비게이션과 같은 원리다. 터널에서 GPS 신호가 끊겨도 속도와 방향으로 현재 위치를 추정하는 것처럼, 눈의 떨림을 무시하고 실제 시선 위치를 부드럽게 추정한다.

> **방금 전 위치 + 움직임 패턴을 고려해서, 튀는 값은 무시하고 가장 그럴듯한 위치를 추정하는 필터**

---

#### 현재 정확도가 낮은 이유

| 증상 | 원인 |
|---|---|
| 가까이 있어야 잘 된다 | 정규화가 불완전해서 |
| 방향은 맞는데 좌표가 틀리다 | 캘리브레이션 포인트 9개로 부족 |
| 커서가 떨린다 | 칼만 필터 파라미터 튜닝 필요 |

---

#### AI Hub 데이터 학습 후 달라지는 것

현재는 MediaPipe가 주는 **뭉툭한 홍채 좌표** (4개 점의 평균)를 사용한다.  
AI Hub 데이터로 학습하면 **픽셀 단위 정밀 동공 중심** 1점을 뽑을 수 있게 된다.

```
현재   → 홍채 4개 점의 평균 (대략적)
학습 후 → 동공 중심을 딱 1픽셀로 (정밀)
```

이 차이가 전체 시선 추적 정확도를 결정하는 핵심이다.
