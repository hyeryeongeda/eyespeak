## 📖 핵심 개념 정리

### var 키워드

할당 값의 타입에 따라서 변수의 타입이 가변적

```java
public static void main(String[] args) {
		int i = 10;
		var a = 1;
		var str = "Hello";
		var list2 = new ArrayList<>();
		var list3 = new ArrayList<>();
}
```

### String

- 기본형이 아닌 참조형임

```java
String str1 = "Hello";
String str2 = "Hello";

String str3 = new String("Hello");
String str4 = new String("Hello");
```

두 방식의 차이는 ?

- str1 과 str2 는 문자열 풀에 저장하여 같은 객체를 가리킴
- str3 와 str4 는 heap 에 새로운 문자열을 만들어 다른 객체를 가리킴

### Wrapper Class 주요 메서드 정리

| 메서드 | 설명 | 예시 | 결과 |
| --- | --- | --- | --- |
| `parseInt()` | String → int | `Integer.parseInt("123")` | `123` |
| `valueOf()` | String/기본타입 → Wrapper | `Integer.valueOf("123")` | `Integer(123)` |
| `toString()` | Wrapper → String | `Integer.toString(123)` | `"123"` |
| `compareTo()` | 값 비교 | `Integer.valueOf(1).compareTo(2)` | `-1` |
| `MAX_VALUE` | 최댓값 상수 | `Integer.MAX_VALUE` | `2147483647` |
| `MIN_VALUE` | 최솟값 상수 | `Integer.MIN_VALUE` | `-2147483648` |
| `toBinaryString()` | 2진수 변환 | `Integer.toBinaryString(10)` | `"1010"` |
| `toHexString()` | 16진수 변환 | `Integer.toHexString(255)` | `"ff"` |
| `toOctalString()` | 8진수 변환 | `Integer.toOctalString(8)` | `"10"` |

### Switch Expressions

기존 switch 코드

```java
int month = 3;
int day = -1;
switch(month) {
		case 2:
				day = 29;
				break;
		case 4:
		case 6:
		case 9:
		case 11:
				day = 30;
				break;
		default:
				day = 31;
}
```

switch expressions

```java
int month = 3;

int day = switch(month) {
		case 2 -> 29;
		
		case 4, 6, 9, 11 -> 30;
		
		default -> {
				yield 31;
		}
}
```

### 객체 지향 프로그래밍

| 특성 | 내용 |
| --- | --- |
| Abstraction(추상화) |   • 현실의 객체를 추상화해서 클래스를 구성한다.
 |
| Polymorphism(다형성) |   • 하나의 객체를 여러 가지 타입(형)으로 참조할 수 있다.
 |
| Inheritance(상속) |   • 부모 클래스의 자산을 물려받아 자식을 정의함으로 코드의 재사용이 가능하다.
 |
| Encapsulation(데이터 은닉과 보호) |   • 데이터를 외부에 직접 노출시키지 않고 메서드를 이용해 보호할 수 있다.
 |
