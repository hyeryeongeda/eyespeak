### 1. 테스트 개요
* **모델명**: L2CS-Net (Learning to Gaze with Cross-Scale Consistency)
* **선정 이유**: 오픈소스 기반의 각도 회귀 시선 추적 모델로,
  ResNet50 backbone을 사용해 Yaw/Pitch 각도를 직접 예측.
  WebSocket 기반 실시간 스트리밍 구현이 가능하고,
  별도 하드웨어 없이 일반 웹캠만으로 동작.
* **주요 기능**:
    * MediaPipe FaceMesh로 얼굴/눈 영역 검출 후 눈 이미지 크롭
    * L2CS-Net으로 Yaw(수평) / Pitch(수직) 시선 각도 예측
    * One Euro Filter로 실시간 떨림 보정
    * 9-point 2차 다항식 캘리브레이션으로 개인별 편향 보정
    * 브라우저 UI에서 실시간 추적 / 캘리브레이션 / 정확도 테스트 제공

### 3. 성능 평가

#### 3.1 정확도 (Accuracy)

**최종 결과 (캘리브레이션 적용, 각도 범위 9°)**

| 지표 | 값 |
| :--- | :--- |
| 평균 각도 오차 | **5.1°** |
| 정확도 (오차 <10°) | **89%** |
| 최고 포인트 (중앙) | 2.5° |
| 최저 포인트 (상단) | 10.5° |

**개선 경과**

| 단계 | 정확도 | 비고 |
| :--- | :--- | :--- |
| 캘리브레이션 없음 | 11% | 평균 오차 46.3° |
| Affine 캘리브레이션 적용 | 56% | 6-파라미터 선형 보정 |
| 2차 다항식 캘리브레이션 + 범위 최적화 | **89%** | 비선형 왜곡 보정 포함 |

* **시선 추적 정밀도**: 화면 중앙부 2~4° 수준으로 우수. 상단 중앙에서 Yaw 편향(9.8°)이 남아 있어 가장 큰 오차 포인트.
* **각도 범위 설정**: ±6.3° (range=9) 에서 최적 성능. 범위를 넓힐수록 모델의 비선형 구간에 진입해 정확도 저하.
* **보정 필요성**: 사용 전 9-point 캘리브레이션 필수 (약 1분 소요). 미보정 시 개인별 편향으로 정확도 급락.

#### 3.2 응답 속도 (Latency & FPS)
* **평균 FPS**: `3.0` FPS (Colab T4 GPU 기준, 서버-클라이언트 왕복 포함)
* **딜레이**: 약 468ms (로컬 실행 시 크게 개선 가능)
* **리소스 소모**: GPU 추론 기반이므로 클라이언트 CPU 부하 없음.
  로컬 GPU 환경에서는 10~30 FPS 수준 예상.

#### 3.3 안정성 (Stability)
| 구분 | 테스트 결과 | 비고 |
| :--- | :--- | :--- |
| **안경 착용** | ⚠️ 오차 증가 | 미착용 기준으로 테스트 진행 |
| **고개 움직임** | ⚠️ 오차 증가 | 정면 고정 시 최적 성능 |
| **주변 밝기** | ⚠️ 오차 증가 | CLAHE 전처리 적용으로 일부 완화 |
| **개인 간 차이** | ⚠️ 캘리브레이션으로 보정 가능 | 단일 피험자(p00) 학습으로 편향 존재 |

### 4. 결론 및 종합 의견

#### 💡 서비스 도입 적합성 (탈출 게임 컨셉)
* **적합 여부**: 부분 도입 가능
* **이유**: 캘리브레이션 후 평균 오차 5.1°, 정확도 89% 수준은
  "특정 구역을 응시하면 트리거" 방식의 인터랙션에 충분히 활용 가능.
  단, 서버(GPU 환경) 필요 및 FPS 3.0(Colab 기준)의 응답 지연은
  실시간 반응성이 중요한 씬에서 체감상 불편함을 줄 수 있음.
  로컬 GPU 환경에서는 FPS가 크게 개선되어 실용적 수준 달성 가능.

#### ⚠️ 도입 시 고려사항
* **캘리브레이션 UX**: 게임 시작 전 보정 과정을 게임 내 스토리와 자연스럽게 결합 필요.
  (예: "시스템 활성화를 위해 9개 지점을 응시하세요" 등)
* **로컬 서버 필요**: FastAPI 백엔드가 GPU 환경에서 실행되어야 하므로
  팀원 각자의 노트북 환경에 따라 성능 편차 발생.
  GPU 없는 경우 CPU 추론으로 FPS 1 이하 가능.
* **각도 범위 제약**: ±6.3° 범위 최적화로 고정 시 화면 전체 추적 정밀도는 낮아질 수 있음.
  게임 화면 레이아웃을 중앙 집중형으로 설계하면 영향 최소화 가능.
* **단일 피험자 학습 한계**: 현재 모델은 MPIIGaze p00 / day20.mat 단 **480개 샘플**로 학습.
  p00 전체(59,922개) 또는 p00~p14 전 피험자 데이터로 재학습 시 일반화 성능 향상 기대.
