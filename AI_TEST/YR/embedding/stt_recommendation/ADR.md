# ADR: 유저 DB 개인화 반영 방식 결정

## 배경

ALS 환자 개인화 추천 시스템에서 유저 DB(172개)와 일반 말뭉치 DB(2,900개)를 함께 사용해 문장을 추천한다.
유저는 이대호 팬 컨셉으로 야구 관련 표현이 많고 usage_count도 높게 설정되어 있다.
그런데 실제로 추천 결과에 유저의 개성(야구, 이대호 관련 표현)이 잘 반영되지 않는 문제가 있다.

---

## 현재 구조

```
[Stage 1] Bi-encoder + 쿼터 분리
  user_db  (172개) → 코사인 유사도 × 가중치 → 상위 14개
  general_db (2,900개) → 코사인 유사도 × 1.0  → 상위  6개
  합산 → 20개 후보
       ↓
[Stage 2] Cross-encoder
  (질문, 문장) 20쌍 → 관련성 점수 → 재정렬 → 상위 5개
       ↓
[Stage 3] LLM
후보 5개 → 상위 3개 선택 → LLM은 시제/어투만 교정 (내용 유지)

```

**가중치 공식:**
```
general 문장: weight = 1.0 (고정)
user 문장:    weight = 1.0 + log(usage_count + 1)  → 최소 1.69 ~ 최대 4.81
```

---

## 문제 정의

가중치는 **코사인 유사도를 증폭**하는 역할만 한다.
질문과 유저 문장 사이의 코사인 유사도 자체가 낮으면 가중치를 아무리 높여도 순위권에 들어오지 못한다.

**예시:**
```
질문: "밥 먹었어?"

"된장찌개 먹었어" (general) → cosine_sim=0.65 × 1.0  = 0.65  ← 상위권
"이대호 최고야"   (user)    → cosine_sim=0.05 × 4.81 = 0.24  ← 하위권
```

결과: 일반 말뭉치가 2,900개로 훨씬 크기 때문에, 질문 주제가 유저 관심사와 다를 경우 유저 표현이 밀려남.

---

## 고려한 해결 방안

### 방안 A: 가중치 더 올리기

user_boost 계수를 추가로 곱해 유저 문장 점수를 강제로 높임.

```
user score = cosine_sim × (1.0 + log(usage_count+1)) × user_boost  # user_boost=2.0~3.0
```

**장점:** 구현 간단, 기존 구조 유지
**단점:** 근본 해결 안 됨. cosine_sim이 0.03이면 × 3해도 0.09. 여전히 밀림.
질문과 완전히 무관한 유저 문장이 올라와 오히려 정확도 하락 위험.

---

### 방안 B: 쿼터 분리 (Separate Quota)

user_db와 general_db를 **따로따로** 상위 N개씩 뽑아 합산.

```
user_db에서 상위 14개  (코사인 유사도 × 가중치 기준)
general_db에서 상위 6개
────────────────────
합쳐서 20개 → Cross-encoder 재랭킹
```

**장점:** 질문 주제와 무관해도 유저 표현이 항상 후보에 포함됨. Cross-encoder가 어차피 관련 없는 건 걸러줌.
**단점:** 질문과 무관한 유저 문장이 후보 슬롯을 차지해 후보 품질 자체가 떨어질 수 있음.
Cross-encoder가 걸러준다 해도 20개 슬롯 중 일부가 낭비됨.

---

### 방안 C: 현재 구조 유지 (경쟁 풀)

지금처럼 전체 경쟁 풀에서 가중치로만 조정.

**장점:** 질문 관련성 기준으로만 후보가 선별되므로 정확도가 높음.
**단점:** 유저의 개성(이대호 팬)이 질문 주제가 야구일 때만 반영됨. 다른 주제에서는 일반 말뭉치가 독점.

---

## 핵심 트레이드오프

| | 유저 개성 반영 | 질문 관련성 | 구현 복잡도 |
|--|--|--|--|
| 방안 A (가중치 boost) | 약함 (근본 해결 아님) | 보통 | 낮음 |
| 방안 B (쿼터 분리) | 강함 (항상 보장) | 다소 낮아질 수 있음 | 낮음 |
| 방안 C (현재 유지) | 주제 일치 시만 반영 | 높음 | 없음 |

---

## 미결 사항

- 이 서비스에서 **"질문에 딱 맞는 답변"** 과 **"유저 개성이 담긴 답변"** 중 어느 쪽이 더 중요한가?
- ALS 환자 입장에서는 주제가 조금 안 맞아도 자기 말투/표현이 나오는 게 더 편할 수 있음 → 방안 B 유리
- 보호자와의 소통 정확도를 우선시한다면 → 방안 C 유지
- Cross-encoder가 최종 필터 역할을 한다는 점에서, 방안 B의 정확도 손실은 생각보다 작을 수 있음
