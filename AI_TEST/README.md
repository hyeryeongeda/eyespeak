# 👁️ AI_TEST: 웹캠 아이트래킹 모델 테스트 및 비교

* 이 폴더는 프로젝트의 핵심 기능인 **웹캠 기반 아이트래킹(Eye-tracking)** 구현을 위해 다양한 AI 모델을 테스트하고 그 결과를 기록하는 공간입니다. 각자 테스트한 모델의 성능과 특징을 정리하여 최적의 모델을 선정하는 기초 자료로 활용합니다.

### 📁 폴더 구조 가이드
- **본인 이니셜(예. `CY`) 폴더** 생성 후 **TEST_REPORT.md (결과 리포트)파일**과 코드를 올려주세요.
- **폴더 전체 업로드는 지양해주세요.** 핵심 필수 파일만 기록용으로 올려주시고, 자세한 기록은 노션 `AI` 페이지에 남겨주시거나 팀원들에게 알리고 싶은 내용은 MM으로 공유합시다!

  ```
    AI_TEST/
    ├── README.md (현재 파일)
    └── [본인_이니셜_파일]/          # 예: CY
        └── [Model_Name]/          # 예: L2CS-NET, YOLO, MediaPipe 등
            ├── src/               # 테스트에 사용한 소스 코드
            └── test_report.md     # 모델별 상세 테스트 결과 리포트
  ```

### 📝 상세 리포트 작성 양식 (TEST_REPORT.md)
* 테스트 결과를 `TEST_REPORT_TEMPLATE.md` 파일 양식을 참고해서 정리해주세요. (LLM에 파일 양식 넣어서 정리해달라고 하기.)
