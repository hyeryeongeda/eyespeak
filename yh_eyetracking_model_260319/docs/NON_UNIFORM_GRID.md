# 비균등 그리드 (선택)

ALS 사용자처럼 시선이 화면 **중심부에 몰리는** 경우, 중심부 해상도를 높이기 위해 yaw/pitch 구간을 균등이 아닌 **비균등**으로 나누는 방안입니다.

## 목적

- 현재: `config_gaze`의 yaw ±25°, pitch ±20°를 **균등 분할** (2×3 또는 3×3).
- 비균등: **캘리브레이션으로 수집한 (yaw, pitch) 분포**의 분위수(quantile)로 구간을 나누거나, 설정에서 “중심 셀 폭 좁게” 옵션을 두어 중심부에 셀을 더 촘촘히 배치.

## 확장 시점

- **캘리 분포 확인 후**: 실제 사용자(또는 테스터)의 N점 캘리 데이터에서 yaw/pitch 분포를 구한 뒤, 구간 경계를 조정.
- **구현 위치**: [config_gaze.py](../config_gaze.py)에 `GRID_BIN_EDGES`(yaw/pitch별 구간 경계 리스트) 또는 `USE_NONUNIFORM_GRID` 플래그 추가. [model.py](../model.py)의 `yaw_pitch_to_cell`에서 해당 경계를 참조하도록 확장.

## 참고

- 우선순위는 1~4단계(캘리 매핑, One-Euro, 파인튜닝, 태스크 지표) 완료 후, 캘리 분포를 수집·분석한 뒤 필요 시 적용합니다.
