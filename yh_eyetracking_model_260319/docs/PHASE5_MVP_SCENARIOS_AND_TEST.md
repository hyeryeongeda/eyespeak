> gaze_server(app_gaze_web) + 선택 모델 연동, 9그리드 HTML과 호환. MVP 기능별 시나리오와 통합 테스트 체크리스트.

## 5-1. 연동 상태

| 항목 | 내용 |
|------|------|
| **서버** | [app_gaze_web.py](../app_gaze_web.py) — Flask, POST /api/gaze (JSON `{ "image": "base64..." }`), GET /api/health, GET / → 9그리드 페이지 |
| **정적 페이지** | [시선_예시/gaze_server_9grid.html](../시선_예시/gaze_server_9grid.html) — 웹캠 → 캡처 → 서버 전송 → yaw/pitch/cell → 9그리드 하이라이트, **1.5초 응시 시 "선택: N" 토스트** (config_gaze.DWELL_TIME_SEC) |
| **모델** | pipeline.GazePipeline, 체크포인트 없으면 스텁(0,0). GAZE_CHECKPOINT 환경변수로 경로 지정 가능. |
| **전처리** | PREPROCESS_CLAHE 환경변수(1/0)로 프레임 CLAHE 적용 여부 (기본 1) |

## 5-2. MVP 기능별 시나리오

| 기능 | 시나리오 (1~2줄) | 통과 |
|------|------------------|------|
| **SOS 긴급 호출** | 침대에 누운 상태에서 SOS 버튼(또는 전용 그리드, 예: 셀 0) 응시 → **즉시(0초)** 알람/호출 동작. (4단계: SOS 즉시 반응) | [ ] |
| **필수 의사소통** | 시간대별 루틴 카테고리 노출 → 환자가 시선으로 문장 그리드 선택 → **1.5초 응시 시 확정** → 문장 표시. | [ ] |
| **자유 의사소통** | 하고 싶은 말 그리드/버튼 시선 선택 → 1.5초 유지 시 확정 → 문장 표시. | [ ] |
| **채팅 + AI 추천** | (선택) 채팅 화면에서 AI 추천 문장 리스트 시선 선택. | [ ] |
| **통증/불편 표현** | (선택) 신체 부위 그리드 시선 선택 → 구체적 요청 표시. | [ ] |

## 5-3. 통합 테스트 체크리스트

- **환경**: 1단계에서 정한 거리·각도·조명(침대 약 60cm, ruz UHD 2160).
- **서버 기동**: `cd ~/yh_eyetracking_model && . .venv/bin/activate && pip install flask && python3 app_gaze_web.py` → 서버에서 `* Running on http://0.0.0.0:5000` 출력 확인.

**접속이 안 될 때 (원격 서버에서 실행·PC 브라우저에서 접속하는 경우)**  
- PC에서 `localhost:5000`은 **본인 PC**를 가리킵니다. 서버가 SSH(예: SSAFY 70.12.130.106)에 있으면 아래 중 하나로 접속하세요.
  1. **서버 IP로 접속**: 브라우저 주소창에 `http://70.12.130.106:5000` (또는 해당 서버 IP). 서버·방화벽에서 **5000 포트 허용**되어 있어야 함.
  2. **SSH 포트 포워딩** (localhost로 쓰고 싶을 때):  
     PC 터미널에서 `ssh -L 5000:localhost:5000 j-j14e205@70.12.130.106` 로 접속한 뒤, 브라우저에서 `http://localhost:5000` 접속. (기존 Cursor SSH와 별도로 터미널 하나 더 열어서 포워딩용으로 사용.)
- 서버가 아직 안 떠 있으면: 서버 터미널에서 `python3 app_gaze_web.py`가 실행 중인지 확인.

- **체크**:
  - [ ] 서버 기동 후 `/` 접속 시 9그리드 페이지 로드
  - [ ] 웹캠 허용 후 시선(얼굴)에 따라 하이라이트 셀 변경
  - [ ] 동일 셀 1.5초 응시 시 "선택: N" 토스트 표시
  - [ ] 선택 안 됨 / 잘못 선택됨 발생 시 기록 (어느 방향에서 어디로 틀리는지)
  - [ ] API: POST /api/gaze (JSON `{"image": "base64..."}`) → `left`/`right` 각각 yaw, pitch, cell 응답
  - [ ] API: GET /api/health → status, model_loaded, device, dwell_time_sec
