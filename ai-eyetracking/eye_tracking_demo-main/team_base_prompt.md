## 프로젝트 개요

**서비스명**: ALS(루게릭) 환자를 위한 안구 추적 기반 의사소통 보조 서비스

**핵심 목표**: 안구 운동만 가능한 ALS 환자가 **최소한의 시선 이동(4회 이내)**으로 원하는 표현에 도달할 수 있도록, 개인화된 추천 시스템을 구현한다.

**프로젝트 환경**:
- SSAFY 프로젝트, 최종 발표일 3월 31일
- 현재 기획 마무리 단계, 곧 개발 착수
- 안구 추적: 웹캠 기반. 현재 미디어파이프로 진행 중이며, AI 담당 팀원이 별도 모델 학습도 병행 중

**SSAFY 평가 기준**:
- **기능 완성도**가 최우선
- 우리가 선택한 기술/로직에 대한 **명확하고 객관적인 근거** (논문, 정량 데이터 등 공신력 있는 자료)

## 서비스 구조

### 두 가지 모드
- **환자 모드**: 안구 추적으로 의사표현을 선택하는 화면
- **보호자 모드**: 환자 데이터 관리, 초기 설문, 추천 설정 등을 담당하는 화면

### 환자 모드 상세

환자는 **4분할 화면 + 안구 두 번 깜박임**으로 총 5가지 행동이 가능하다.
- 4분할: 화면을 4개 영역으로 나누고, 시선을 해당 영역에 고정하면 선택
- 안구 두 번 깜박임: 주로 뒤로가기/이동에 사용

#### 메인 화면 (4분할)
| 영역 | 기능 |
|------|------|
| 1 | **호출** - 보호자에게 알림 전송 |
| 2 | **일반 소통** - 일상적 의사표현 |
| 3 | **신체/통증 소통** - 통증 부위별 특화 소통 |
| 4 | **커스텀 소통** - 여가 생활 지원 (유튜브, 오디오북 등 API/URL 연동) |

#### 소통 기능 공통 구조
- 기능마다 어느 정도 차이가 있지만, 기본적으로 **추천 3개 + 직접 입력 1개**의 4분할 구조로 진행된다.

#### 기타 기능
- **즐겨찾기**: 자주 사용하는 표현에 빠르게 접근. 메인 페이지에 구현하고 싶으나 5분할로 해야 할지 등 구체적 방식은 미확정
