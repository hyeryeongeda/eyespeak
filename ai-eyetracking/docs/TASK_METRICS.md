# 태스크 레벨 평가 지표

LOPO MAE(degree)와 함께, **실사용에 가까운 지표**를 정의해 모델/파이프라인 비교와 개선 방향을 잡습니다.

## 지표 정의

### 1. 그리드 셀 정확도 (Grid Cell Accuracy)

- **의미**: 예측 셀과 정답 셀이 일치하는 비율.
- **측정**: `scripts/measure_offline_accuracy.py` — CSV(path, yaw_deg, pitch_deg) 기준으로 gt_cell = yaw_pitch_to_cell(gt_yaw, gt_pitch), pred_cell은 파이프라인 출력. 일치 건수 / 유효 샘플 수.
- **목표**: 높을수록 좋음. 6칸 그리드에서 무작위는 약 16.7%.

### 2. Dwell 구간 안정성 (셀 경계 지터)

- **의미**: 일정 시간(예: dwell time 1.5초) 동안 **같은 셀에 머물렀는지**, 셀 경계를 넘나드는 횟수(jitter)가 적은지.
- **오프라인**: CSV 행 순서를 시퀀스로 간주할 때, 연속한 두 프레임에서 예측 셀이 바뀐 횟수. `cell_changes / max(1, N-1)` 로 정규화하면 “프레임당 셀 전환률”로 보고 가능.
- **실시간**: 로그 또는 프론트에서 dwell 구간(사용자가 한 칸을 응시하는 구간)별로 “해당 구간 내 예측 셀 변경 횟수” 수집. 적을수록 안정적.

### 3. 의도한 셀 선택까지 시간 (Time to Select)

- **의미**: 실사용 시나리오에서 “N번 셀을 선택하라”는 과제를 주었을 때, **첫 프레임부터 해당 셀이 dwell time을 만족할 때까지** 걸린 시간.
- **측정**: 실험 프로토콜 필요. 예: 1~6번을 순서대로 선택하게 하고, 각 번호마다 “시선을 옮긴 시점 ~ 선택 확정 시점” 구간을 측정해 평균·분포 보고.
- **목표**: 짧을수록 사용성 좋음. dwell time(1.5초) 이상은 최소 필요 시간.

## 오프라인 스크립트 연동

- **measure_offline_accuracy.py**: MAE(yaw, pitch), 그리드 정확도, **셀 전환률**(연속 프레임 간 예측 셀 변경 비율, `cell_transition_rate`) 출력. JSON 저장 시 포함.
- 실시간 “의도한 셀 선택까지 시간”은 실험 프로토콜·로그 수집이 필요하므로 별도 도구로 확장.

## 참고

- LOPO MAE는 학술 벤치마크용. 실서비스에서는 그리드 정확도·dwell 안정성·선택 시간이 체감 품질과 직결됩니다.
