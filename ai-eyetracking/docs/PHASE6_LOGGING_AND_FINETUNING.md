# 6단계: 지속 개선 — 로깅·파인튜닝·재측정

> 실사용 로그/수집 설계(익명화, 환자 동의), 실환경 소량 데이터 확보, 파인튜닝 스크립트, 3·4·5단계 지표 재측정.

---

## 6-1. 실사용 로그/수집 설계

| 항목 | 내용 |
|------|------|
| **목적** | 시선·선택 패턴 수집 → 파인튜닝/검증용 또는 UX 분석. 환자 동의·프라이버시 필수. |
| **수집 항목 (익명화)** | 타임스탬프, 그리드 인덱스(0~8), yaw/pitch(도), 선택 확정 여부. **캠 이미지/얼굴 미수집** 시 익명 유지. |
| **저장 형식** | JSONL 또는 CSV. 개인식별자 없음, 기기/세션 ID는 익명 ID로 대체. |
| **동의** | 이용 약관·동의 화면에서 "시선·선택 로그 수집" 명시, 거부 시 수집 안 함. |
| **구현** | 서버에서 /api/gaze 호출 시 선택적으로 로그 파일에 append. [gaze_log.jsonl](../gaze_log.jsonl) 참고. |

---

## 6-2. 실환경 소량 데이터 확보

| 항목 | 내용 |
|------|------|
| **목표** | 2단계 최소 규모(클래스당 100 등)에 맞춘 검증셋 또는 파인튜닝용 이미지. |
| **출처** | 직접 수집(1단계 카메라·거리) 또는 동의 하에 로그 연동 수집. |
| **레이블** | 시선 각도(yaw/pitch) 또는 그리드 인덱스. 캘리브레이션 시점의 화면 좌표→각도 변환 가능. |

---

## 6-3. 파인튜닝 / 재학습

- **스크립트**: [scripts/finetune_gaze.py](../scripts/finetune_gaze.py) — GazeNet (및 추후 L2CS-Net) 실환경 데이터로 파인튜닝.
- **입력**: 이미지 폴더 + 레이블 CSV(path, yaw_deg, pitch_deg).
- **산출물**: 새 체크포인트. 기존 checkpoints/best.pt 백업 후 교체 또는 별도 파일로 저장.

---

## 6-4. 재측정·재테스트

- **오프라인**: `scripts/measure_offline_accuracy.py` — 새 체크포인트로 MAE·그리드 정확도 재측정.
- **실시간**: `scripts/measure_realtime_latency.py` — FPS·지연 재측정.
- **통합**: 5단계 체크리스트·MVP 시나리오 다시 실행, 개선 여부 기록.
