# B-3: 안구(홍채) 전용 Eye-tracking 모델 — 데이터셋·라이브러리 조사 및 2단계 플랜

## 목표

얼굴 전체가 프레임에 정상적으로 들어오지 않아도, **안구(또는 홍채) 영역만**으로 시선 추정이 가능한 모델을 검토·설계한다.  
기획 배경(MediaPipe 한계, 루게릭 환자 특성)은 [PROJECT_BACKGROUND.md](PROJECT_BACKGROUND.md) 참고.

## 1. 데이터셋 조사

| 데이터셋 | 설명 | 입력 형태 | 비고 |
|----------|------|-----------|------|
| **MPIIGaze** | 15명, 21만 장 이상, 자연스러운 노트북 사용 환경 | 얼굴/눈 패치 | in-the-wild, 눈 영역만 사용 가능 |
| **Gaze360** | 360° 시선 방향 | 얼굴/눈 | 극단적 각도 포함 |
| **ETH-XGaze** | 110명, 100만 장 이상, 18대 카메라, 극단적 헤드포즈·시선 | 224×224/448×448 얼굴 패치, full image | 대규모, 표준 프로토콜 |
| **GazeCapture** | 1,450명+, 250만 프레임, 모바일 | 얼굴·눈 | iTracker CNN, 눈만 크롭해 사용 가능 |
| **GazeTrack** | 1만 장, 416×416 눈(peri-ocular) 영역, 홍채 경계·중심 레이블 | 눈 영역, 홍채 마스크/파라미터 | 홍채 중심 기반 시선에 적합 |
| **GazeTrack Lab (2025)** | ±30° FOV, IR 카메라, 47명, pupil mask·ellipse·3D gaze | 단안 IR 눈 영역 | 고정밀, IR 환경 |

- **안구만 입력** 실험: MPIIGaze, GazeCapture, GazeTrack 등에서 **눈 크롭**만 추출해 사용하는 선행 연구·코드가 있음 (예: One Eye is All You Need).

## 3. 2단계 플랜 (안구 전용 모델)

Part A(MediaPipe + 헤드포즈 + 데모) 및 B-1/B-2(홍채 수식·스무딩)가 안정화된 뒤 진행.

| 단계 | 작업 | 산출물 |
|------|------|--------|
| 1 | **데이터셋 선정** | MPIIGaze 또는 GazeCapture 등에서 **눈 크롭만** 추출하는 전처리 스크립트, 레이블(yaw/pitch 또는 3D gaze) 매핑 |
| 2 | **입출력 규격** | 입력: 눈 이미지 **64×64**(그레이스케일 또는 3채널). 출력: (yaw_deg, pitch_deg) 및 그리드 셀(0~5 또는 0~8) |
| 3 | **모델 설계** | 경량 백본 + multi-task(회귀+셀 분류). 아래 "모델 설계 보완" 참고. |
| 4 | **학습·평가** | 선정 데이터로 학습, 검증셋 각도 오차·그리드 정확도·태스크 지표 측정. 도메인 갭 고려. |
| 5 | **파이프라인 연동** | MediaPipe로 눈/안구 크롭 추출 → 안구 전용 모델 추론 → 기존 `yaw_pitch_to_cell`·캘리와 연동 |

### 모델 설계 보완 (64×64 눈 입력)

- **백본**: 64×64 눈 크롭에는 ResNet18이 과한 경우가 있음. **MobileNetV3-Small** 또는 **EfficientNet-B0** 수준 경량 백본 검토 → 추론 속도·소규모 데이터 과적합 완화.
- **Multi-task**:
  - **Head 1**: (yaw_rad, pitch_rad) 회귀 (기존과 동일).
  - **Head 2**: 그리드 셀(0~5 또는 0~8) 분류.
  - **Loss**: `L = L_reg + λ * L_cls`. 학습·평가 시 회귀 MAE와 셀 정확도 둘 다 기록.
- **전처리**: Dataset 설계(리사이즈 64×64, CLAHE, 정규화)는 기존 문서와 동일. 그레이스케일 또는 3채널 중 하나로 통일.

---

## 4. 주의점

- **난이도**: 데이터 전처리·레이블 정합, 실환경과 데이터셋 간 도메인 갭, 학습 비용이 큼.
- **우선순위**: 단기에는 B-1/B-2(홍채 수식 + 스무딩)만으로도 “미디어파이프 딸깍” 이상의 차별화 가능. 안구 전용 모델은 발표·고도화 목표가 있을 때 2단계로 진행 권장.
